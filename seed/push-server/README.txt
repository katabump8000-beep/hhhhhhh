سيرفر الإشعارات (بديل دوال Firebase، لا يحتاج خطة Blaze ولا بطاقة)

1) ارفع مجلد push-server إلى مستودعك أو إلى منصة الاستضافة التي تشغّل عليها بوتك (يلزم Node 18 أو أحدث).
2) أنشئ متغير بيئة اسمه FIREBASE_SERVICE_ACCOUNT وضع فيه كل محتوى ملف JSON (نفس مفتاح حساب الخدمة).
   لا ترفع ملف المفتاح نفسه إلى مستودع عام أبداً.
3) أمر التشغيل: npm install ثم npm start
4) يجب أن يبقى السيرفر يعمل دائماً. إن توقف توقفت الإشعارات خارج التطبيق.
